# HOWTO — name a thing correctly

This is a **how-to**. One outcome: name a thing correctly. Authority for names is [VOCABULARY.md](VOCABULARY.md) only. This page does not restate axioms.

---

## Outcome

You use the frozen name for the concept, or you know the name is rejected.

## Steps

1. Open [VOCABULARY.md](VOCABULARY.md).
2. Look up the concept in [Frozen nouns](VOCABULARY.md#frozen-nouns) or [Frozen verbs](VOCABULARY.md#frozen-verbs).
3. If the word you wanted is not there, check [Rejected primary names](VOCABULARY.md#rejected-primary-names) and use the listed name instead.
4. If the confusion is Cap vs trace vs Activity, read that comparison in [VOCABULARY.md](VOCABULARY.md#cap-vs-trace-vs-activity). Do not copy it here.
5. Supporting terms that are not extra kernel nouns: [VOCABULARY.md](VOCABULARY.md#supporting-terms-not-extra-kernel-nouns).

Gloss and synonym rules live in VOCABULARY.md. This page does not restate them.
